Changelog

Every release and what changed in it. This page is generated from CHANGELOG.md in the repository, so it cannot say a different thing from the file — and each version heading links the full diff on GitHub.

Also in Korean, from 3.20.1

The Korean changelog starts at 3.20.1. Earlier releases were written up in English only and are deliberately not backfilled: inventing a translation of a release nobody wrote one for would be worse than saying where the record begins. A test fails the build if a release from 3.20.1 on appears in one language and not the other.

Release archives, checksums, SBOMs and the signed build provenance for each version are on the releases page. To upgrade, run hostveil update.
